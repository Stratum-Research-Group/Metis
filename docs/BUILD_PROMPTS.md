# Production build prompts

These are the prompts to use **when starting each new project**. They replace the `.txt` drafts as implementation briefs. The earlier `*-review.md` files remain as design rationale; they are not build prompts.

1. [Phylax](phylax-build-prompt.md) — policy and guarded capability execution.
2. [Kybernetes](kybernetes-build-prompt.md) — orchestrator and stable client API.
3. [Prosopon](prosopon-build-prompt.md) — secure local text/voice interface.
4. [Paideia](paideia-build-prompt.md) — audited learning pipeline after outcome data exists.

Read [the shared stack build contract](STACK_BUILD_CONTRACT.md) with every prompt. It names existing integration mismatches and defines versioned contracts and release gates. The sequence allows Phylax to guard Kybernetes actions before the UI exposes them; Paideia can scaffold earlier using fixtures but cannot claim a trained routing improvement until real paired outcomes are available.
