# Krisis (Κρίσις)

**Krisis** (Greek: *judgment* / *decision*) is the candidate answer selector, eligibility gating, deduplication, and quality scoring engine of the Metis local AI ecosystem.

It evaluates candidate answers generated by language models (or internal search and deliberation components), enforces strict factual grounding through versioned verifiers, filters candidates via hard eligibility gates, and selects the optimal response according to an audited, machine-readable policy manifest.

---

## 1. Architecture & Pipeline

Krisis operates as a deterministic, fail-closed selection pipeline:

```
Request (Candidates, Question Class, Capabilities, Evidence)
  │
  ├── 1. Snapshot Freshness Check
  │      └─ If evidence changed & rebuilds exhausted -> Abstain STALE
  │
  ├── 2. Upstream Generation Failure Check
  │      └─ If all candidate generation failed -> Abstain UPSTREAM_GENERATION_FAILED
  │
  ├── 3. Class Routing Matrix (Normalizes question class -> profile or typed abstention)
  │      ├─ closed_form_number / entity / choice -> grounded_v1 (logprobs) or grounded_support_only
  │      ├─ unclassified / unknown -> grounded_support_only
  │      ├─ requires_grounding=true & verifier_active=false -> Abstain VERIFIER_UNAVAILABLE
  │      ├─ requires_grounding=false -> eligibility_baseline (unverified)
  │      └─ conflicting multi-class -> Abstain PROFILE_UNAVAILABLE
  │
  ├── 4. Exact Lineage Deduplication
  │      └─ Exact text + citation spans; negation differences preserved
  │
  ├── 5. Hard Eligibility Gates (Pre-score elimination)
  │      ├─ Access authorization (caller is permitted to view underlying sources)
  │      ├─ Provenance validity (valid document/passage IDs in knowledge store)
  │      ├─ Contradiction check (no direct contradiction with retrieved facts)
  │      ├─ Citation resolution (all bracketed citations [1], [doc:123] resolve to valid evidence IDs)
  │      └─ Per-claim support verification (every claim must be 'supported' with conf >= per_claim_min)
  │
  ├── 6. Feature Validation & 6-Decimal Half-Even Scoring
  │      ├─ grounded_v1: score = 0.7 * mean_claim_confidence + 0.3 * cal_ll
  │      ├─ grounded_support_only: score = mean_claim_confidence
  │      └─ Missing required features (e.g. cal_ll under grounded_v1) -> FEATURE_INVALID
  │
  ├── 7. Quality Threshold (tau) Gate
  │      └─ score >= tau (boundary equality score == tau passes)
  │
  └── 8. Selection / Terminal Precedence
         ├─ If survivors: select highest score (lowest ULID/candidate ID tie-break); warn on partial upstream failure
         └─ If no survivor: map gate/feature failures to aggregate reason via reason_precedence
```

## 2. Policy Manifest & Profiles

Krisis decisions are governed by a schema-validated policy manifest (`krisis-policy-0.1.json`) strictly validated against JSON Schema (`krisis-policy.schema.json`). (Note: manifests and claim verdicts are schema-validated at runtime; treat draft policies as schema-checked declarations).

### Active Profiles

| Profile ID | Kind | $\tau$ Threshold | Per-Claim Min | Description |
| :--- | :--- | :--- | :--- | :--- |
| `grounded_v1` | `grounded` | `0.700000` | `0.700000` | Requires claim support and calibrated log-likelihood (`cal_ll`). |
| `grounded_support_only` | `grounded` | `0.850000` | `0.700000` | Support-only scoring when logprobs are disabled or unavailable. |
| `eligibility_baseline` | `baseline` | `None` | `None` | Unverified path when `requires_grounding=false`. |

### Half-Even Decimal Arithmetic

To prevent floating-point platform drift across hardware architectures, scoring strictly uses Python `decimal.Decimal` with `ROUND_HALF_EVEN` quantized to 6 decimal places:

$$\text{score} = \text{quantize}\left(0.7 \cdot \bar{c} + 0.3 \cdot \text{cal\_ll}, 10^{-6}\right)$$

### Reason Precedence Hierarchy

When no candidate survives eligibility gates and thresholds, Krisis reports an aggregate abstention reason selected via strict precedence order:

1. `NO_AUTHORIZED_CANDIDATE` (Failed access gate)
2. `NO_PROVENANCE_CANDIDATE` (Failed provenance gate)
3. `CONTRADICTED_CANDIDATE` (Failed contradiction gate)
4. `CITATION_UNRESOLVED` (Invalid or missing citation markers)
5. `CLAIM_UNSUPPORTED` (Unverified or refuted claims)
6. `QUALITY_BELOW_THRESHOLD` (Score $< \tau$)
7. `NO_VALID_CANDIDATE` (Feature validation errors or empty candidates)

## 3. Installation & Quickstart

Krisis requires Python `>=3.11`. Dependencies: `pydantic`, `jsonschema`, `click`, `tabulate`.

```bash
# Set up environment
uv venv .venv --python 3.12
source .venv/bin/activate

# Install in editable mode with development dependencies
uv pip install -e ".[dev]"
```

## 5. Pure-Policy Fixture Matrix (`krisis-fixtures-0.1.json`)

All 16 test cases reproduce exact determinism:
- **A**: Supported vs. fluent-unsupported ($c_1$ claim unsupported $\to$ rejected; $c_2$ score $0.870000 \ge 0.700000 \to$ selected).
- **A2**: Support-only path without logprobs ($c_2$ score $0.900000 \ge 0.850000 \to$ selected).
- **B**: Asymmetric missing feature (`cal_ll` missing under `grounded_v1` $\to$ `FEATURE_INVALID` maps to `NO_VALID_CANDIDATE`).
- **C**: Stale snapshot on recheck (Evidence changed, `rebuilds_remaining: 0` $\to$ `STALE`).
- **D**: Mixed gate failures ($c_1$ fails access, $c_2$ fails contradiction $\to$ `NO_AUTHORIZED_CANDIDATE` wins precedence).
- **E**: Verifier outage under `requires_grounding=true` $\to$ `VERIFIER_UNAVAILABLE`.
- **F**: $n=1$ candidate faces $\tau$ threshold ($0.627000 < 0.700000 \to$ `QUALITY_BELOW_THRESHOLD`).
- **G**: Non-grounded request falls to `eligibility_baseline` (lowest lexicographic ID `01JAAA` selected, labeled `unverified`).
- **H**: Deduplication of exact text and identical citation spans ($c_1$ absorbs $c_2$ with lineage; $c_3$ negation kept separate).
- **I.1**: Unclassified query routes to `grounded_support_only`.
- **I.2**: Compatible multi-class routes combine.
- **I.3**: Conflicting multi-class routes abstain `PROFILE_UNAVAILABLE`.
- **I.4**: Unknown query class normalizes to `unclassified` $\to$ `grounded_support_only`.
- **J**: Prompt injection inside evidence text treated strictly as data.
- **K**: Boundary score equality ($0.700000 == 0.700000 \to$ passes threshold).
- **L**: Partial upstream failure with valid survivor ($c_1$ selected with `UPSTREAM_GENERATION_FAILED_PARTIAL` warning).
