# Krisis

**Krisis** (Greek: *judgment* / *decision*) is the candidate answer selector, eligibility gating, deduplication, and quality scoring engine of the Metis ecosystem.

It evaluates candidate answers generated by language models (or internal search components), enforces strict factual grounding through versioned verifiers, filters candidates via hard eligibility gates, and selects the optimal response according to an audited, machine-readable policy manifest.

---

## 1. Architecture & Pipeline

Krisis operates as a deterministic, fail-closed selection pipeline:

```
Request (Candidates, Question Class, Capabilities, Evidence)
  │
  ├── 1. Snapshot Freshness Check (Abstain STALE if evidence changed & rebuilds exhausted)
  │
  ├── 2. Upstream Generation Failure Check (Abstain UPSTREAM_GENERATION_FAILED if all attempts failed)
  │
  ├── 3. Class Routing Matrix (Normalizes question class -> profile or typed abstention)
  │      - closed_form_number / entity / choice -> grounded_v1 (logprobs) or grounded_support_only
  │      - unclassified / unknown -> grounded_support_only
  │      - requires_grounding=true & verifier_active=false -> abstain VERIFIER_UNAVAILABLE
  │      - requires_grounding=false -> eligibility_baseline (unverified)
  │      - conflicting multi-class -> abstain PROFILE_UNAVAILABLE
  │
  ├── 4. Exact Lineage Deduplication (Exact text + citation spans; negation differences preserved)
  │
  ├── 5. Hard Eligibility Gates (Pre-score elimination)
  │      - Access authorization
  │      - Provenance validity
  │      - Contradiction check
  │      - Citation resolution
  │      - Per-claim support verification (Every claim must be 'supported' with conf >= per_claim_min)
  │
  ├── 6. Feature Validation & 6-Decimal Half-Even Scoring
  │      - grounded_v1: 0.7 * mean_claim_confidence + 0.3 * cal_ll
  │      - grounded_support_only: mean_claim_confidence
  │      - Missing required features (e.g. cal_ll under grounded_v1) -> FEATURE_INVALID
  │
  ├── 7. Quality Threshold (tau) Gate (score >= tau; boundary equality passes)
  │
  └── 8. Selection / Terminal Precedence
         - If survivor: select highest score (or lowest ULID tie-break); warn on partial upstream failure
         - If no survivor: map gate/feature failures to aggregate reason via reason_precedence
```

## 2. Installation & Environment

Krisis requires Python `>=3.11`. Dependencies: `pydantic`, `jsonschema`, `click`, `tabulate`.

```bash
# Set up environment
uv venv .venv --python 3.12
source .venv/bin/activate

# Install in editable mode with development dependencies
uv pip install -e ".[dev]"
```

---

## 3. CLI Commands

| Command | Description |
| :--- | :--- |
| `krisis validate-schema` | Validate policy manifest against `krisis-policy.schema.json` |
| `krisis replay` | Replay all 16 pure-policy fixtures from `krisis-fixtures-0.1.json` |
| `krisis evaluate <req.json>` | Evaluate candidate answers from a JSON request file |
| `krisis inspect-policy` | Display active profiles, thresholds, and reason precedence |

## 4. Test Suite & Fixture Verification

Run unit tests and test coverage:
```bash
pytest -v --cov=krisis --cov-report=term-missing
```

### Pure-Policy Fixture Matrix (`krisis-fixtures-0.1.json`)
All 16 cases reproduce identical status, selected ID, rejection reasons, and 6-decimal scores:
- **A**: Supported vs. fluent-unsupported ($c_1$ claim unsupported $\to$ rejected; $c_2$ score $0.870000 \ge 0.700000 \to$ selected)
- **A2**: Support-only path without logprobs ($c_2$ score $0.900000 \ge 0.850000 \to$ selected)
- **B**: Asymmetric missing feature (`cal_ll` missing under `grounded_v1` $\to$ `FEATURE_INVALID` maps to `NO_VALID_CANDIDATE`)
- **C**: Stale snapshot on recheck (Evidence changed, `rebuilds_remaining: 0` $\to$ `STALE`)
- **D**: Mixed gate failures ($c_1$ fails access, $c_2$ fails contradiction $\to$ `NO_AUTHORIZED_CANDIDATE` wins precedence)
- **E**: Verifier outage under `requires_grounding=true` $\to$ `VERIFIER_UNAVAILABLE`
- **F**: $n=1$ candidate faces $\tau$ threshold ($0.627000 < 0.700000 \to$ `QUALITY_BELOW_THRESHOLD`)
- **G**: Non-grounded request falls to `eligibility_baseline` (lowest lexicographic ID `01JAAA` selected, labeled `unverified`)
- **H**: Deduplication of exact text and identical citation spans ($c_1$ absorbs $c_2$ with lineage; $c_3$ negation kept separate)
- **I.1**: Unclassified query routes to `grounded_support_only`
- **I.2**: Compatible multi-class routes combine
- **I.3**: Conflicting multi-class routes abstain `PROFILE_UNAVAILABLE`
- **I.4**: Unknown query class normalizes to `unclassified` $\to$ `grounded_support_only`
- **J**: Prompt injection inside evidence text treated strictly as data
- **K**: Boundary score equality ($0.700000 == 0.700000 \to$ passes threshold)
- **L**: Partial upstream failure with valid survivor ($c_1$ selected with `UPSTREAM_GENERATION_FAILED_PARTIAL` warning)
